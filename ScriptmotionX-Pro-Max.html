This version is a front-end prototype. You can create and save project briefs, preview uploaded images, plan scenes and manage character notes. It does not currently generate real videos, voices, images, user accounts or payments.

Next development step: build a secure backend, connect an AI video provider, add authentication and configure storage. Keep API keys on the server, never in browser JavaScript.
